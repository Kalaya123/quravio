🚀 GitHub Deploy Guide

Host Quravio free on GitHub Pages — live in 5 minutes.

Step 1 — Create GitHub Account

Go to github.com and sign up free. Verify your email.

Step 2 — Create Repository

Click + → New repository

Name: quravio  •  Visibility: Public  •  Click Create

Step 3 — Upload All 7 Files

In your repo: Add file → Upload files
index.html quravio-shop.html quravio-product.html quravio-checkout.html quravio-about.html quravio-contact.html quravio-admin.html
Click Commit changes

Step 4 — Enable GitHub Pages

Repo → Settings → Pages → Source: Deploy from branch → main / root → Save

Your live URL:
https://YOUR-USERNAME.github.io/quravio/

Step 5 — Custom Domain (Optional)

Buy at Namecheap. In Pages settings → Custom domain → enter it.
DNS: CNAME www → YOUR-USERNAME.github.io

🔒 Firestore Security Rules

Firebase Console → Firestore → Rules → paste → Publish:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /products/{id} { allow read: if resource.data.status == 'active'; allow write: if false; } match /orders/{id} { allow create: if true; allow read, update, delete: if false; } match /customers/{id} { allow create: if true; allow read, update, delete: if false; } match /settings/{id} { allow read, write: if false; } } }

🔗 Firebase Code for Shop Pages

Add to quravio-shop.html and quravio-product.html to load products:
<script type="module"> import { initializeApp } from "https://www.gstatic.com/firebasejs/11.0.0/firebase-app.js"; import { getFirestore, collection, getDocs, query, where } from "https://www.gstatic.com/firebasejs/11.0.0/firebase-firestore.js"; const app = initializeApp({ apiKey: "AIzaSyAbE76HZVyfiVw0SyHNzpAxRCeb_uLCW7Y", authDomain: "quravio-store.firebaseapp.com", projectId: "quravio-store" }); const db = getFirestore(app); const snap = await getDocs( query(collection(db,'products'), where('status','==','active')) ); const products = snap.docs.map(d => ({ id: d.id, ...d.data() })); // products[] now has: name, price, images[], description, category, stock </script>
